# Channel media assets

The channel bot can publish the launch series as text immediately. When `SHAURMEG_CHANNEL_ASSET_BASE_URL` is configured, it automatically attempts to attach the matching media file before falling back to text.

Expected public files:

- `01-start-here.mp4`
- `02-product-system.jpg`
- `03-guest-path.mp4`
- `04-owner-console.jpg`
- `05-connect-steps.jpg`
- `06-order-flow.mp4`
- `07-individuality.jpg`
- `08-realcity.mp4`
- `09-menu-experience.mp4`
- `10-comparison.jpg`
- `11-faq.jpg`
- `12-connect-now.mp4`

Recommended image size: 1080×1350.  
Recommended vertical video size: 1080×1920, H.264/AAC, Telegram-friendly bitrate.

The full art direction and storyboards are in `v2/channel/LAUNCH_PLAN.md`.
